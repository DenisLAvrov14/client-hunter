## Фаза 0 — источники данных (раздел 7.1)

### OpenStreetMap / Overpass API — ✅ (с лимитами)
- **Дата:** 2026-10-21
- **Источники:** [Overpass commons / usage policy](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html), [OSMF Licence & Legal FAQ](https://osmfoundation.org/wiki/Licence/Licence_and_Legal_FAQ)
- **Вывод:**
  - Публичный инстанс overpass-api.de: ориентир **≤ ~10 000 запросов/сутки и ≤ ~1 ГБ/сутки**. Число слотов на клиента — динамическое (`/api/status`, строка «Rate limit»). При превышении — HTTP 429; по ресурсам — 504. Таймаут запроса по умолчанию 180 с, память 512 МиБ.
  - ODbL: share-alike касается только **публичного использования/распространения**. Внутренняя БД, которую никто, кроме оператора, не видит, — не «public use», делиться не нужно. Факт происхождения записи храним в `company_sources` (source_id = `osm`) — этого достаточно.
- **Решение для кода:** один запрос на (город × сегмент), разумный `[timeout:...]`, перед запросом проверять `/api/status`, на 429 — ждать, а не повторять сразу. Наш объём (десятки запросов в сутки) далеко ниже лимитов.

### Companies House API — ✅
- **Дата:** 2026-10-21
- **Источник:** [Companies House — Rate limiting](https://developer-specs.company-information.service.gov.uk/guides/rateLimiting)
- **Вывод:** **600 запросов за 5 минут** на приложение. Сверх лимита — 429 до конца окна. Систематическое превышение/обход — бан без предупреждения. Ключ бесплатный.
- **Решение для кода:** клиентский лимитер ~1 запрос/сек (300 за 5 минут — с запасом ×2), на 429 — пауза до конца окна.

### Adzuna API — ❌ ИСКЛЮЧЁН (решение оператора 2026-10-21)
- **Дата:** 2026-10-21
- **Источник:** [Adzuna API Terms of Service](https://developer.adzuna.com/docs/terms_of_service)
- **Вывод:**
  - Бесплатный ключ — для оценки; коммерческим организациям — 14-дневный trial, после него **для любого продукта, приносящего выручку или лиды, нужен лицензионный договор**.
  - **Sales prospecting / lead generation прямо требуют письменного согласия Adzuna.**
  - «Contacting third parties, even where they provide listings content» — нарушение, ведёт к немедленному отзыву доступа. Наш сценарий (вакансия → работодатель → холодное письмо) под это попадает.
- **Решение оператора (2026-10-21):** Adzuna не используем. Источника вакансий для UK/IE/NL нет; триггер `job_posting` в этих рынках будет пустым (trigger_score = 0), пока не появится разрешённый источник.

### HeadHunter API (hh.ru / hh.kz) — ⚠
- **Дата:** 2026-10-21
- **Источник:** OpenAPI-спецификация `https://api.hh.ru/openapi/specification/public` (операция `get-vacancies`, раздел «Требования к запросам»)
- **Вывод:**
  - Обязателен заголовок `User-Agent` (или `HH-User-Agent`) с названием приложения и контактом, иначе 400.
  - Цитата: «**Если не передан токен авторизации, то после первого запроса будет предложено пройти капчу.**» — анонимный поиск фактически недоступен; капчи мы не обходим (спека, п. 0.5).
  - Глубина выдачи ≤ 2000 результатов на запрос.
- **Решение:** использовать только с **токеном приложения** (регистрация приложения на dev.hh.ru — делает оператор). Перед подключением в Фазе 5 — прочитать условия использования API hh.ru на предмет использования данных работодателей для коммерческих обращений (в публичной спецификации их нет). До этого — источник выключен. RU/KZ и так стоят в конце очереди запуска.

### Brave Search API — ⚠ (опционально)
- **Дата:** 2026-10-21
- **Источник:** [brave.com/search/api](https://brave.com/search/api/)
- **Вывод:** Search — **$5 за 1000 запросов**, ежемесячно $5 бесплатных кредитов (≈1000 запросов), до 50 QPS. Хранить результаты можно **только на плане с «storage rights»**; какие планы их включают — на странице не указано.
- **Решение:** нам нужно хранить найденный домен компании → нужен план со storage rights. Перед подключением (Фаза 5) — уточнить в документации цен/у Brave. На старте не используем.

### PageSpeed Insights API — ✅
- **Дата:** 2026-10-21
- **Источники:** [Google: Get started with PSI API](https://developers.google.com/speed/docs/insights/v5/get-started); квоты — сторонние обзоры ([unlighthouse](https://unlighthouse.dev/learn-lighthouse/pagespeed-insights-api/rate-limits), [PostHog](https://posthog.com/docs/data-warehouse/sources/google-pagespeed-insights))
- **Вывод:** работает и без ключа, но для автоматизации ключ рекомендован. С ключом — **25 000 запросов/сутки** на проект; кратковременный лимит в источниках расходится (400 за 100 с или ~240/мин). Заголовков rate-limit API не отдаёт.
- **Решение:** ключ обязателен, ≤ 1 запрос/сек, нам нужно 2 замера на компанию. Точную квоту оператор видит в Google Cloud Console → Quotas.

### Shopify: признаки и `/products.json` — ⚠ (проверить в Фазе 1 на живых магазинах)
- **Дата:** 2026-10-21
- **Источники:** [Shopify community: robots.txt](https://community.shopify.com/t/robots-txt/397645), [shopify.dev: robots.default_groups](https://community.shopify.dev/t/robots-default-groups-returns-an-older-rule-set-than-the-robots-txt-shopify-serves-by-default/38352), [Apify Shopify scraper](https://apify.com/scrapyx/shopify-products-scraper) (сторонний)
- **Вывод:** robots.txt у Shopify генерируется платформой, по умолчанию закрывает admin/cart/checkout/orders/account и параметры сортировки; магазин может добавить `Disallow: /*.json` — тогда `/products.json` трогать нельзя. Нужен RFC 9309-совместимый матчер с wildcard (Python `urllib.robotparser` ошибается на `/*.json`; для Node — проверить `robots-parser` на тестах). Заголовки `x-shopid` / `x-shopify-stage` официально **не подтверждены**.
- **Решение:** детект по `cdn.shopify.com` в ресурсах и `Shopify.theme` в HTML (основные), заголовки — только как дополнительный признак. Тест на `Disallow: /*.json` обязателен в Фазе 1.
