# Настройка почты для холодных писем

Делает оператор. Нужно до Фазы 3, прогрев — минимум 2 недели до Фазы 4.

## 1. Отдельный домен
- Купить домен, **похожий на основной, но не основной** (например, основной `example.dev` → для писем `example-studio.com` или `getexample.com`). Если домен для писем попадёт в спам-списки, основной не пострадает.
- Регистратор — любой с нормальным управлением DNS (Cloudflare Registrar, Porkbun, Namecheap).
- На домене — простой сайт-визитка: имя, чем занимаешься, 2 кейса (Pinpinpin, CryptoVigil), контакт. Плюс страница `/bot`: что делает `ClientHunterBot`, контакт для жалоб, как исключить свой сайт. Ссылка на неё стоит в User-Agent (spec 8.2).

## 2. Почтовый провайдер
Нужен **SMTP + IMAP** с паролем приложения. Варианты:

| Провайдер | Плюсы | На что смотреть |
|---|---|---|
| Google Workspace | лучшая доставляемость, лимит 2000 писем/сутки | ~$7+/мес; Program Policies запрещают спам — у нас 15–20 персональных писем/день, это не массовая рассылка, но прочитай политику |
| Zoho Mail | дёшево | **сторонние обзоры пишут, что AUP Zoho запрещает cold email** — прочитай [Anti-Spam Policy](https://www.zoho.com/mail/anti-spam-policy.html) до покупки |
| Migadu | дёшево, без лимита на ящики | на младших тарифах маленький лимит исходящих (по отзывам ~20/день на Micro) — сверь с [pricing](https://www.migadu.com/pricing/) |

Рекомендация: **Google Workspace, 1 ящик** (`имя@домен`). Запиши выбор и ссылку на политику провайдера в `docs/verification-log.md`.

## 3. DNS
Все записи — в DNS домена для писем. Значения для SPF/DKIM даёт провайдер.

| Запись | Тип | Пример (Google Workspace) |
|---|---|---|
| MX | MX | по инструкции провайдера |
| SPF | TXT на `@` | `v=spf1 include:_spf.google.com ~all` |
| DKIM | TXT на `google._domainkey` | ключ из админки провайдера (2048 бит) |
| DMARC | TXT на `_dmarc` | `v=DMARC1; p=none; rua=mailto:dmarc@<домен>` |

- DMARC начинаем с `p=none` (только отчёты). Через месяц без проблем — `p=quarantine`.
- Проверка: `npm run check-dns` (появится в Фазе 3) + вручную через [mail-tester.com](https://www.mail-tester.com/) — цель 9/10 и выше.

## 4. Прогрев (минимум 2 недели)
- **Неделя 1:** только обычная переписка вручную: 3–5 писем в день знакомым/себе на другие ящики, с ответами. Подписаться на пару рассылок.
- **Неделя 2:** 5–10 писем в день, по-прежнему живые, с ответами.
- **После старта Фазы 4:** `daily_cap` UK = 15, глобально `MAX_SENDS_PER_DAY=20`. Не больше 20–30 писем в день на ящик суммарно.
- Сервисы автопрогрева (взаимная переписка ботов) **не используем** — они нарушают политики большинства провайдеров.

## 5. Правила, которые соблюдает код
- Plain text, без картинок, без вложений, без трекинг-пикселей и редиректных ссылок.
- Одно письмо раз в 2–8 минут, только в окне `send_window_local` рынка.
- Bounce rate > 5% за 7 дней → автопауза.

## 6. Что внести в `.env` после настройки
```
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=имя@домен
SMTP_PASS=<пароль приложения>
IMAP_HOST=imap.gmail.com
IMAP_PORT=993
IMAP_USER=имя@домен
IMAP_PASS=<пароль приложения>
SENDER_NAME=Имя Фамилия
SENDER_EMAIL=имя@домен
SENDER_WEBSITE=https://домен
```
`SENDING_ENABLED` и `DRY_RUN` не трогать до Фазы 4.
