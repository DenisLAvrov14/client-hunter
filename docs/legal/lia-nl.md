# Оценка законного интереса (LIA) — NL

**Право:** AVG (GDPR) + Telecommunicatiewet 11.7 · **Заполняет:** оператор · **Статус:** не заполнено

> Шаблон. Пока он не заполнен и `legal_review_done: true` не выставлен в `config/markets/nl.yaml`, отправка на рынок NL заблокирована.

## 1. Цель (purpose test)
- Какой интерес преследуем? *(предложение B2B-услуг веб-разработки компаниям с конкретной проблемой на сайте)*
- Законен ли он? Есть ли выгода для получателя?

## 2. Необходимость (necessity test)
- Можно ли достичь цели с меньшим объёмом данных? *(храним только ролевой адрес компании, домен, публичные сведения с сайта)*
- Есть ли менее навязчивый способ?

## 3. Баланс (balancing test)
- Чьи данные обрабатываем? *(юрлица; ролевые адреса; именные — только если профиль рынка разрешает)*
- Ожидает ли получатель такого обращения? *(адрес опубликован на сайте как контакт для бизнеса)*
- Меры защиты: одно письмо + не более N follow-up, отказ одним словом, suppression навсегда, минимум данных, срок хранения.

## 4. Срок хранения
- Компании без ответа: удалять досье через ___ месяцев.
- Suppression list: бессрочно (иначе нельзя гарантировать «больше не пишу»).

## 5. Права субъекта
- Куда человек пишет запрос на доступ/удаление: ___
- Ссылка на privacy notice на домене для писем: ___

## 6. Вывод
- [ ] Законный интерес есть и не перевешивается правами получателей.
- Дата: ___ · Подпись: ___
